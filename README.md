# AvukoOS

**AvukoOS** — Debian 13 (Trixie) asosida qurilgan, interfeysi 100% o'zbek tilida
(yangi lotin alifbosi: ö, ğ, ş, ç) bo'lgan erkin operatsion tizim.

Rasmiy sayt: **https://os.avuko.uz** · Hamjamiyat: **https://t.me/avuko_chat**

## Yuklab olish (1.0 "Tong")

ISO fayllar [**Releases**](../../releases/latest) bo'limida:

| Nashr | Hajmi | Tavsif |
|-------|-------|--------|
| **Desktop (XFCE)** | ~1.4 GB | Uy va kundalik foydalanish uchun ish stoli |
| **Server** | ~677 MB | Grafik boshqaruv paneli bilan server |
